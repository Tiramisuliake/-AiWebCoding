# /next

## 用途

建议下一项最有价值的工作。

## 先读

1. `docs/project-state.md`
2. `docs/todos.md`
3. `docs/business-module-guide.md`
4. 当前 `git status --short`

## 步骤

1. 判断工作区是否有未完成改动。
2. 查看开放待办和当前项目阶段。
3. 优先选择能推进业务开发或减少文档/代码漂移的工作。
4. 推荐一个主要下一步，并最多给出两个备选。

## 输出

返回：

- 推荐下一项任务。
- 为什么它重要。
- 开始时应阅读的文件/文档。
- 该任务的验收标准。
