# 待办清单模板

| Status | Priority | Module | Task | Acceptance | Source | Updated |
|---|---|---|---|---|---|---|
| open | P2 | module-name | Describe the work | Describe how done is verified | request/docs/code | YYYY-MM-DD |

## 字段说明

- Status: `open`, `in_progress`, `blocked`, `done`, `dropped`
- Priority: `P0`, `P1`, `P2`, `P3`
- Module: 业务模块或系统区域
- Task: 一句话说明要做什么
- Acceptance: 可验收结果
- Source: 来源，如用户请求、代码审查、验收记录
- Updated: 最近更新时间
