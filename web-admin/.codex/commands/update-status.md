# /update-status

## 用途

在完成有意义的工作后，更新项目状态和待办。

## 先读

1. `.codex/docs/project-state.md`
2. `.codex/docs/todos.md`
3. 当前变更文件和最近检查结果。

## 步骤

1. 判断发生了什么变化，以及是否已经完成。
2. 当项目能力或阶段变化时，更新 `.codex/docs/project-state.md`。
3. 在 `.codex/docs/todos.md` 中关闭已完成任务或新增后续事项。
4. 如果用户可见流程已验证，增加验收记录。
5. 使用事实化、带日期的描述。

## 输出

返回：

- 已更新的状态字段。
- 新增/关闭的待办。
- 验收记录路径。
- 剩余后续事项。
