# web-admin Codex 资料索引

本目录集中存放 Codex 专用资料，不放业务源码。

## 目录

- `.codex/docs/`：当前项目文档真理源。
- `.codex/commands/`：仓库内命令手册。
- `.codex/templates/`：业务模块和文档模板。
- `.codex/skills/`：只对本项目生效的项目级技能。

## 推荐阅读顺序

1. `../AGENTS.md`
2. `.codex/docs/index.md`
3. `.codex/docs/project-state.md`
4. 按任务读取对应命令或技能。

## 项目级技能

- `.codex/skills/git-workflow/SKILL.md`：当前项目双远端 Git 推送与发版规则。
