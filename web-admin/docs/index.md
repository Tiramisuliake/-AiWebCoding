# 文档索引

`docs/` 是当前项目的文档真理源，供 Agent 和工程师共同使用。

## 新窗口先读

1. `AGENTS.md`
2. `docs/project-state.md`
3. 与任务相关的子系统指南：
   - `backend/AGENTS.md`
   - `frontend/AGENTS.md`
4. 修改 API 行为时读 `docs/api-contracts.md`。
5. 修改权限、角色或菜单时读 `docs/rbac-and-menu.md`。

## 业务开发先读

1. `docs/business-module-guide.md`
2. `templates/业务模块模板.md`
3. `docs/api-contracts.md`
4. `docs/rbac-and-menu.md`
5. `docs/development-workflow.md`
6. `commands/dev.md` 或 `commands/crud.md`

## 验证与状态先读

1. `docs/todos.md`
2. `docs/project-state.md`
3. `docs/acceptance/`
4. `docs/decisions.md`
5. `docs/invariants.md`
6. `commands/check.md`
7. `commands/progress.md`

## 命令手册

| 命令 | 文件 | 用途 |
|---|---|---|
| `/start` | `commands/start.md` | 在新窗口快速理解项目。 |
| `/dev` | `commands/dev.md` | 基于业务文档开发功能。 |
| `/crud` | `commands/crud.md` | 按统一模式新增 CRUD 模块。 |
| `/check` | `commands/check.md` | 运行代码与文档检查。 |
| `/sync` | `commands/sync.md` | 按当前代码同步文档。 |
| `/next` | `commands/next.md` | 建议下一项有价值工作。 |
| `/progress` | `commands/progress.md` | 生成项目进度报告。 |
| `/update-status` | `commands/update-status.md` | 更新项目状态和待办。 |
| `/add-todo` | `commands/add-todo.md` | 添加结构化待办。 |
| `/init-docs` | `commands/init-docs.md` | 修复缺失的文档骨架。 |
