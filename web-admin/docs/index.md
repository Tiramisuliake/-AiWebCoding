# Documentation Index

`docs/` is the current project truth source for agents and engineers.

## New Window Reading Path

1. `AGENTS.md`
2. `docs/project-state.md`
3. The nearest subsystem guide:
   - `backend/AGENTS.md`
   - `frontend/AGENTS.md`
4. `docs/api-contracts.md` when touching API behavior.
5. `docs/rbac-and-menu.md` when touching permissions, roles, or navigation.

## Business Development Reading Path

1. `docs/business-module-guide.md`
2. `templates/业务模块模板.md`
3. `docs/api-contracts.md`
4. `docs/rbac-and-menu.md`
5. `docs/development-workflow.md`
6. `commands/dev.md` or `commands/crud.md`

## Verification And Status Reading Path

1. `docs/todos.md`
2. `docs/project-state.md`
3. `docs/acceptance/`
4. `docs/decisions.md`
5. `docs/invariants.md`
6. `commands/check.md`
7. `commands/progress.md`

## Command Playbooks

| Command | File | Purpose |
|---|---|---|
| `/start` | `commands/start.md` | Quickly understand the project in a new window. |
| `/dev` | `commands/dev.md` | Develop a feature from business docs. |
| `/crud` | `commands/crud.md` | Add a CRUD module consistently. |
| `/check` | `commands/check.md` | Run code and documentation checks. |
| `/sync` | `commands/sync.md` | Sync docs with code behavior. |
| `/next` | `commands/next.md` | Suggest the next useful work. |
| `/progress` | `commands/progress.md` | Produce a project progress report. |
| `/update-status` | `commands/update-status.md` | Update status and todos. |
| `/add-todo` | `commands/add-todo.md` | Add a structured todo. |
| `/init-docs` | `commands/init-docs.md` | Recreate missing doc skeletons. |
